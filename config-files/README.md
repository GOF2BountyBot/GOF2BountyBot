# Official-Config
(private) The config setup for the official deploy of BountyBot, including GOF2 item definitions.

# Using This Config
Open a terminal/cmd instance, and cd into your BountyBot installation.
```
cd GOF2BountyBot
```

Then, clone this repository directly into it.
```
git clone https://github.com/GOF2BountyBot/Official-Config.git config-files
```

When running BountyBot, simply pass the path to the toml config file:
```
python3 main.py config-files/test.toml
```
